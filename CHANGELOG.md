# Changelog

## 1.0.0 — Initial public release

- Renamed the project from the development name IceLanceHelper to ShatterPulse.
- Added Frozen target tracking for Frost Nova, Frostbite, Freeze and configured hard-freeze auras.
- Added Fingers of Frost tracking with a separate top proc indicator.
- Added Retail-inspired split frost overlay.
- Added adjustable glow, opacity, scale, spacing, flash speed and flash strength.
- Added optional Ice Lance icon display modes.
- Added five bundled frost proc sounds.
- Added separate sound toggles for Freeze and Fingers of Frost.
- Added minimap configuration button.
- Added preview modes for Frozen, FoF and Both.
- Added Blizzard-style settings window with General, Visuals, Sounds, Preview and FAQ / About pages.
- Added FAQ and diagnostics.
- Created by Schrubber.
